## The word

**Ghosted.**

One word, no explanation, no apology, no closure — just like the ex it describes. They didn't break up with you. They just... stopped existing. Seen at 21:47, reply never came. The verdict writes itself.

## How it works

`main.ts` writes the single word `Ghosted` to `/output/entry.txt` (UTF-8, 7 characters, one word — inside the 1–111 character gate).

## Run

```sh
node main.ts
cat /output/entry.txt
# Ghosted
```

Node 22+ (type stripping) or any TS runner. Standard library only, no network, no input files.
